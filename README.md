# 关于本项目

## 硬件环境

本项目使用的是 **Fujitsu LIFEBOOK U9310X 的单裸主板**（“无头骑士”环境）。仅有主板本体，**不包含**屏幕、电池、键盘、触控板、机身或其他笔记本配件；相关配置与结论不一定适用于完整笔记本。

我原本计划将 u9310x 安装为黑苹果，用于运行 Claude Code、ChatGPT 和 Grok，组成 Vibe Coding 的「御三家」。

但后来 ChatGPT 发布了 Linux 桌面版；我在 Debian 13 上实际使用后，整体运行良好。同时，黑苹果对硬件的兼容性与维护要求较高，尤其可能增加固态硬盘的负担和发热；macOS 与其他操作系统之间的数据、工具和设备协作也不够方便。

因此，我决定放弃黑苹果路线，改用 **Debian 13 Desktop**。

如果你同样是为了使用各类 AI 编程工具（harness），建议优先考虑 Debian 13 Desktop。至少在与 Windows 11 的文件、网络和日常协作方面，它会方便许多。

## 配置文件与使用建议

具体的 EFI 和配置文件可能包含敏感信息，因此不便上传到本仓库。请不要直接套用他人的配置；建议在 AI（例如 Opus、Sol）的指导下，结合自己的硬件逐项核对、配置并完成安装。

## 免责声明与重要提醒

本仓库仅供参考。请先充分了解相关操作及风险；若操作导致硬件或数据损坏，后果请自行承担。

黑苹果环境下固态硬盘可能出现极高的发热。务必仔细阅读仓库中的说明文件并按指引操作，**不要随意套用或混用配置**。
